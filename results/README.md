# Derived results

Only compact, paper-supporting results are published here.

| File | Purpose |
|---|---|
| `condition_metrics.csv` | Aggregate extraction/linking metrics and subgroup values |
| `paired_bootstrap_effects.csv` | Paired model/pipeline effects with 95% CIs |
| `attribution_matrix.csv` | Primary attribution classifications |
| `threshold_sensitivity.csv` | 3/5/10-point threshold sensitivity |
| `linking_subset_accuracy_cis.csv` | Ambiguous/unambiguous linking accuracy CIs |
| `run_completion_summary.json` | Run-count and zero-failure completion summary |

The raw MedMentions corpus, item-level benchmark text, and full provider response logs are not redistributed.
